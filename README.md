# Expense Tracker

A simple SQLite database for tracking personal expenses and practicing SQL.

## Files
- schema.sql — table definitions
- seed.sql — sample data
- queries.sql — analysis queries (spending by category, top purchases, etc.)

## Setup
1. Install sqlite3
2. Run: sqlite3 expenses.db < schema.sql
3. Run: sqlite3 expenses.db < seed.sql
4. Open: sqlite3 expenses.db
